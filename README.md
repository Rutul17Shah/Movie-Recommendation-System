📊 Movie Recommendation & Analytics Dashboard

🔍 Overview

This project combines machine learning and business intelligence to analyze movie ratings and generate personalized recommendations. It includes a Python-based recommendation system and an interactive Power BI dashboard for data visualization.

⚙️ Features

 Movie recommendation system using KNN (collaborative filtering)
 Data cleaning and preprocessing using Pandas
 Interactive Power BI dashboard

Analysis of:

Movie popularity
Rating distribution
User behavior patterns

🛠 Tools & Technologies

Python (Pandas, NumPy, Scikit-learn)
Power BI
Jupyter Notebook

📈 Dashboard Preview

🧠 How It Works

Clean and preprocess movie and rating datasets
Build a KNN model to compute similarity between movies
Generate recommendations based on user input
Visualize insights using Power BI dashboards

🚀 Key Insights

Most user ratings fall between 3–5, indicating positive trends
Popular movies receive significantly higher engagement
Recommendation system identifies patterns beyond simple genre matching
